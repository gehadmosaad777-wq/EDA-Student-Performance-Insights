# Student Performance - Exploratory Data Analysis (EDA)
## 📌 Project Overview
This project performs an Exploratory Data Analysis (EDA) on student performance data to analyze relationships, examine data distributions, and detect outliers.
## 🛠️ Tools & Libraries
* Python (Pandas, Matplotlib, Seaborn)
* Kaggle Notebooks
## 📊 Key Findings
* **Statistical Summary:** Applied `.info()` and `.describe()` to evaluate basic statistics and confirm data integrity.
* **Distributions & Outliers:** Used Histograms and Boxplots to confirm data distribution and check for anomalous values.
* **Correlations:** Built Heatmaps and Scatterplots to identify key linear relationships between variables.
## 📁 Repository Structure
* `student_performance_eda.ipynb`: Jupyter Notebook with full analysis.
* `student_performance_eda_report.pdf`: PDF report generated from analysis.
* `student_performance_dataset.csv`: Dataset used for the study.
